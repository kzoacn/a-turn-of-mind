[在线游玩](https://kzoacn.github.io/a-turn-of-mind/) · [直接进入第 51 关](https://kzoacn.github.io/a-turn-of-mind/#level=51)

“借位工坊”是游戏中收藏一百件机关的地方。原型曾使用这一名称，旧设计文档和 Godot 原型保留原名。

主试玩版使用原生 HTML / CSS / JavaScript / SVG，现在共有一百关、十间工坊，每关颜色全部不同。通过不同的群、生成元与运动结构产生不同的操作体验，前五十关与原有存档继续保留。Godot 原型完整保留，见 [GODOT_README.md](GODOT_README.md)。

直接双击 **[index.html](index.html)**，或者 Windows 下双击 **[StartGame.bat](StartGame.bat)**。无需安装引擎、依赖或启动服务器，可以离线游玩。进度保存在本机，不发送数据。

开发时也可运行 `python3 tools/serve.py`，然后打开 <http://localhost:8765>。直接打开文件与 HTTP 打开属于不同存储来源，进度分别保留；更换浏览器也会使用另一份进度。

最新关卡可直接从 [第 51 关](https://kzoacn.github.io/a-turn-of-mind/#level=51) 开始，也可以从展柜选择新工坊。每间显示十关，手机上十间入口分两行排列。

第 6、7 关初态和目标完全相同，生成元改变后最短距离从 5 步变为 3 步。第 9 关有意安排为两步休息关。主线没有步数或时间限制，群名和记号放在可选的机关手记中。

第二间关卡的最短解为 3–8 步。第 17、18 关也是同群、同初态、同目标的对照，最短距离分别为 5、6 步。第 13 关使用实际三维旋转的二维投影；第 15、19 关的房间会成组移动。

第三间的最短解为 2–7 步。第 24、25 关初态和目标完全相同，换把手后从 4 步变成 2 步；第 21、29 关则以不同的群作用展示同一个 D₄。第 22 关的颜色位于灯架的棱上，抽屉和方窗也有各自的新轨迹。

第四间的最短解为 2–8 步，第五间为 3–9 步。新内容包括六向风标、联动星桥、七星侧袋、双页与玻璃三棱镜。第 33、34 关及第 44、45 关继续比较同群同目标下的不同工具；第 48、49 关则使用不同的群，同步把手恰好更适合这一目标，让最短距离从 9 步降为 5 步。第 50 关首次同时提供四枚把手。

每种颜色还有独特形状，方便辨识。提示从结构思路逐渐过渡到当前局面的一步建议。关卡可自由选择，动画与声音可以调整。展柜下方可以导出本地试玩记录；反馈表见 [docs/NATIVE_PLAYTEST.md](docs/NATIVE_PLAYTEST.md)。

生成关卡并运行逻辑测试：

```bash
python3 tools/design_web_levels.py
node --test tests/native_logic.cjs
```

浏览器验收需先启动本地服务器，再执行：

```bash
npm --prefix .tools/browser install @playwright/test@1.63.0 --no-audit --no-fund
node .tools/browser/node_modules/playwright/cli.js install chromium
node tests/native_browser.cjs
```

也可用环境变量 `BORROWED_MOVES_CHROMIUM` 指向已有 Chromium。测试使用临时上下文，结果与截图写入 `test-results/native/`。修改中文内容后可运行 `python3 tools/build_native_font.py` 更新字体子集，此可选工具需要 fontTools。已提供的字体无需重新生成即可运行。

运行 `python3 tools/package_native.py` 生成 `build/BorrowedMoves-native-web.zip`，解压后双击其中的 `index.html`。网页无需构建步骤和外部服务。

GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 让 GitHub 直接托管静态文件。提交并推送 `main` 后，Pages 会自动更新；部署方式和验证记录见 [PAGES_DEPLOYMENT.md](docs/PAGES_DEPLOYMENT.md)。线上版的进度保存在当前浏览器，本地版和线上版的进度分别保留。

保留的 Godot 版本：Windows 双击 `StartGodot.bat`；编辑器打开 `project.godot`；旧 Web 导出通过 `python3 tools/serve.py --legacy-godot --port 8766` 访问。原来的 `tools/build.py` 仍负责 Godot 导出。
